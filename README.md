# AntiDeepfake VK Video Analyzer

**Проект для конкурса «IT-Планета 2026»**  
Браузерное расширение и бэкенд-сервис для обнаружения дипфейков в видео ВКонтакте.

---

## 🧠 О проекте

Проект представляет собой **браузерное расширение для Chrome**, которое позволяет пользователям быстро проверять видео на страницах VK на наличие признаков дипфейка. Серверная часть на FastAPI скачивает видео, анализирует лица (OpenCV DNN + FaceNet) и аудиодорожку (спектральные признаки, RMS‑VAD), а затем возвращает вероятность подделки. Результат отображается в попапе расширения с цветовой индикацией.

Проект создан в рамках отборочного этапа конкурса «IT-Планета 2026» (направление «Антидипфейк: Вызов 2026»). Основная цель — предоставить простой и быстрый инструмент для массового пользователя, позволяющий отличить реальное видео от синтезированного прямо в браузере.

---

## 🛠️ Технологии

- **Бэкенд**: Python 3.13, FastAPI, uvicorn, yt-dlp, OpenCV, keras-facenet, librosa, numpy, SQLite.
- **Детекция лиц**: OpenCV DNN (Caffe-модель) с последующим извлечением эмбеддингов через FaceNet.
- **Анализ аудио**: librosa (MFCC, спектральные признаки) + RMS‑VAD (без внешних зависимостей).
- **Кэширование**: SQLite (хеш видео → результат).
- **Расширение**: Manifest V3, JavaScript, Chrome Storage API.

## 📦 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/yourusername/antideepfake-vk.git
cd antideepfake-vk
```

### 2. Настройка бэкенда

#### Требования
- Python 3.13 (или 3.10–3.13)
- Установленный `ffmpeg` (должен быть в PATH)

#### Установка зависимостей
```bash
cd backend
pip install -r requirements.txt
```

#### Файлы модели для детекции лиц
Создайте папку `analyzer/models` и скачайте в неё два файла:
- [`deploy.prototxt`](https://raw.githubusercontent.com/opencv/opencv/master/samples/dnn/face_detector/deploy.prototxt)
- [`res10_300x300_ssd_iter_140000_fp16.caffemodel`](https://github.com/opencv/opencv_3rdparty/raw/dnn_samples_face_detector_20170830/res10_300x300_ssd_iter_140000_fp16.caffemodel)

#### Переменные окружения
Создайте файл `.env` в папке `backend` со следующим содержимым:
```env
VK_ACCESS_TOKEN=ваш_токен_доступа_vk
```
Токен можно получить, создав Standalone-приложение VK и сгенерировав ключ доступа с правами `video`.

#### Запуск сервера
```bash
python main.py
```
Сервер запустится на `http://localhost:8000`. Документация API доступна по адресу `http://localhost:8000/docs`.

### 3. Установка расширения Chrome

1. Откройте Chrome и перейдите на `chrome://extensions/`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `extension` из репозитория.
4. Расширение появится в панели инструментов. Убедитесь, что бэкенд запущен.

## 🚀 Использование

1. Откройте любую страницу с видео во ВКонтакте (например, `https://vk.com/video-123456_789012`).
2. Нажмите на иконку расширения в панели инструментов.
3. Нажмите кнопку **«Проверить видео»**.
4. Через несколько секунд в попапе отобразится результат:
   - 🟢 **Подлинное** – вероятность дипфейка <30%
   - 🟡 **Подозрительное** – вероятность 30–60%
   - 🔴 **Дипфейк** – вероятность >60%
5. Результат сохраняется в кэше и будет показан при повторном открытии попапа на той же странице.

> ⚠️ Первый запуск может занять больше времени из‑за загрузки моделей (FaceNet, Wav2Vec2). Последующие проверки будут быстрее.

## 🧪 Тестирование

Для тестирования использовались:
- **Реальные видео** – официальные записи пресс-конференций, новостные сюжеты (источники: RT, ТАСС, Первый канал).
- **Дипфейки** – созданы с помощью DeepFaceLab и онлайн-сервисов.

**Результаты (на выборке из 10 видео):**
- Реальные видео: средняя вероятность дипфейка = 12% (все определены как `authentic`).
- Дипфейки: средняя вероятность = 68% (4 из 5 определены как `deepfake`, 1 – `suspicious`).

Более подробные результаты можно посмотреть в презентации проекта.
